# LYSH Living
Run: `npm install` then `npm run dev` (develop) or `npm run build` (output in `dist/`, upload its contents to your host).
- Add or edit properties, links and copy in `src/data.js` (sample items are marked `sample: true`).
- Replace the text wordmark in `Logo` (`src/components/ui.jsx`) with the real logo file.
- Contact form: connect the TODO in `src/components/Contact.jsx` to your backend or form service.
- Colours and fonts: `tailwind.config.js`.
